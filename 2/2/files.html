使い方

1. 印刷して紙で解く　各プリント右上の「印刷 / PDF保存」ボタンを押すと、問題用紙だけが印刷されます（解答は印刷されません）。

2. 解答も印刷したいとき　同じく「印刷に解答・解説を含める」にチェックを入れると、解答・解説が別ページとして印刷されます。丸つけ用に。

3. 端末で解くとき　「答えを開く」形式のクイズは、対策サイト側で確認できます。

4. 直前に見直す　対策サイトの「自己チェック」と、このページの単元一覧を見比べて、抜けている単元だけ解き直しましょう。

GitHubで公開する手順

この一式は静的ファイルだけなので、GitHub Pages にそのまま置けます（ビルド不要）。

# 1) 展開したフォルダで
cd ch1-midterm-site
git init
git add .
git commit -m "Add midterm study site"
git branch -M main

# 2) 自分のリポジトリを作って push
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main

3) GitHub のリポジトリ → Settings → Pages → Source を「Deploy from a branch」、Branch を main / / (root) に設定。
数分後 https://<ユーザー名>.github.io/<リポジトリ名>/ で公開されます。相対リンク（prints/…）もそのまま動きます。
